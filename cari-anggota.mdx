# Cari Anggota

Fitur search, digunakan untuk mencari anggota. Langkah untuk search:

1. Login ke website, kemudian klik menu **Search.**
   <Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1785834918723-vo44x1ij6hk-pasted-image-1785834917653.png?fm=auto&auto=compress%2Cformat" width="1917" height="970" alt="" />
2. System akan menampilkan form untuk memasukkan id siswa.
3. **Input&#x20;**&#x49;d Kartu atau Nama Kartu.
4. System akan menampilkan hasil dari pencarian.
5. Klik pad&#x61;**&#x20;Hasil Pencarian.**
   <Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1785834979751-bvp1pbuq8kr-pasted-image-1785834978973.png?fm=auto&auto=compress%2Cformat" width="1918" height="968" alt="" />
6. System akan menampilkan **Detail Siswa.**
