### Informasi yang ditampilkan

Halaman Presensi menampilkan kalender bulanan dengan warna per status kehadiran, serta bagian **Presensi Harian** yang menunjukkan **Jam Masuk** dan **Jam Keluar** pada tanggal yang dipilih. Status kehadiran yang dikenal aplikasi:

| Status        | Keterangan                          |
| ------------- | ----------------------------------- |
| **Hadir**     | Siswa hadir                         |
| **Terlambat** | Hadir namun terlambat               |
| **Izin**      | Tidak hadir dengan izin             |
| **Sakit**     | Tidak hadir karena sakit            |
| **Alpa**      | Tidak hadir tanpa keterangan        |
| **Libur**     | Hari libur (dari kalender akademik) |

Tersedia dua tombol lanjutan:

- **Rekap Presensi**: daftar presensi per bulan/tahun dengan filter status (Semua, Hadir, Alpa, Izin, Sakit, Terlambat); setiap catatan menampilkan tanggal, badge status, Jam Masuk/Jam Keluar, dan keterangan.
- **Presensi Pelajaran**: rekap kehadiran per mata pelajaran dalam bentuk diagram donat beserta jumlah Hadir, Alpa, Sakit, Izin, dan Terlambat, dengan filter bulan dan mata pelajaran.

## Presensi Kegiatan

Setelah langkah ini, Anda melihat jadwal presensi kegiatan siswa.

<Steps>
  <Step title="Buka menu Akademik" title-type="p">
    Tekan menu **Akademik**.
  </Step>

  <Step title="Pilih Presensi Kegiatan" title-type="p">
    Tekan sub menu **Presensi Kegiatan**.
  </Step>

  <Step title="Lihat jadwal" title-type="p">
    Jadwal presensi kegiatan akan terlihat.
  </Step>
</Steps>

## Jadwal Pelajaran

Setelah langkah ini, Anda melihat jadwal pelajaran siswa per hari beserta materi dan tugasnya.

<Steps>
  <Step title="Buka menu Akademik" title-type="p">
    Tekan menu **Akademik**.
  </Step>

  <Step title="Pilih Jadwal Pelajaran" title-type="p">
    Tekan sub menu **Jadwal Pelajaran**, maka akan terlihat jadwal pelajaran per hari.
  </Step>

  <Step title="Lihat detail pelajaran" title-type="p">
    Tekan pada pelajaran untuk melihat materi pelajaran dan tugas (jika ada).
  </Step>
</Steps>

<Callout kind="info" collapsed="false">
  Halaman **Detail Mapel** menampilkan bagian _Informasi Mata Pelajaran_: **Mata Pelajaran**, **Waktu Pelajaran**, **Materi Pelajaran**, dan **Tugas Pelajaran** (dapat dibuka-tutup).
</Callout>

## Kalender Akademik

Menu **Kalender Akademik** menampilkan kalender bulanan berisi event dan hari libur sekolah, lengkap dengan pencarian event per bulan dan daftar event di bawah kalender (menu **List Event** untuk daftar lengkap).

**Link Panduan Kalender Akademik : [https://drive.google.com/file/d/1eCcoeHP55oFdqIEIPqeWGK1VZpNPJoyQ/view?usp=sharing](https://drive.google.com/file/d/1eCcoeHP55oFdqIEIPqeWGK1VZpNPJoyQ/view?usp=sharing)**

Setelah langkah ini, Anda akan melihat kalender akademik

<Steps>
  <Step title="Buka menu Akademik" title-type="p">
    Tekan menu akademik

    <Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1793239888632-8u9ejxoxx3x-pasted-image-1793239885557.png?fm=auto&auto=compress%2Cformat" width="219" height="490" alt="" style="width: 219px; height: auto; cursor: pointer;" />
  </Step>

  <Step title="Pilih Kalender Akademik" title-type="p">
    **Tekan sub menu Kalender Akademik**

    <Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1793240023346-ya6mj7p5z1a-pasted-image-1793240020074.png?fm=auto&auto=compress%2Cformat" width="233" height="522" alt="" style="width: 233px; height: auto; cursor: pointer;" />
  </Step>

  <Step title="Melihat Kalender Akademik" title-type="p">
    Halaman Kalender Akademik menampilkan kalender bulanan yang berisi informasi event akademik dan hari libur sekolah.

    Pada halaman ini, pengguna dapat melakukan beberapa hal berikut:

    - **Pencarian Event:** Masukkan kata kunci pada kolom pencarian untuk mencari event pada bulan yang sedang ditampilkan.
    - **Navigasi Bulan:** Tekan tombol panah kiri untuk melihat bulan sebelumnya dan tombol panah kanan untuk melihat bulan berikutnya.
    - **Memilih Bulan dan Tahun:** Tekan nama bulan dan tahun untuk memilih periode kalender yang ingin ditampilkan.
    - **Melihat Event Berdasarkan Tanggal:** Pilih tanggal pada kalender untuk melihat event yang berlangsung pada tanggal tersebut.
    - **Melihat Semua Event:** Tekan tombol _Lihat Semua_ pada bagian List Event untuk melihat daftar event secara lengkap.

    Apabila tidak terdapat event pada tanggal atau periode yang dipilih, halaman akan menampilkan informasi bahwa tidak ada data event.

    <Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1793240301064-54edfntx6ve-pasted-image-1793240297722.png?fm=auto&auto=compress%2Cformat" width="314" height="689" alt="" style="width: 314px; height: auto; cursor: pointer;" />
  </Step>

  <Step title="Melihat Daftar Event" title-type="p">
    Tekan tombol **Lihat Semua** pada bagian List Event di halaman Kalender Akademik untuk membuka halaman List Event. Halaman ini menampilkan daftar event akademik dan hari libur sekolah yang dikelompokkan berdasarkan bulan dan tahun.

    Pada halaman List Event, pengguna dapat melakukan beberapa hal berikut:

    - **Mencari Event:** Gunakan kolom pencarian untuk menemukan event berdasarkan kata kunci.
    - **Melihat Informasi Event:** Setiap event menampilkan nama kegiatan dan tanggal pelaksanaannya.
    - **Melihat Daftar Event:** Gulir halaman untuk melihat daftar event pada bulan-bulan berikutnya.

    <Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1793240501245-u6ee0ae95di-pasted-image-1793240498509.png?fm=auto&auto=compress%2Cformat" width="305" height="683" alt="" style="width: 305px; height: auto; cursor: pointer;" />
  </Step>

  <Step title="Detail Event" title-type="p">
    Tekan salah satu event pada halaman List Event untuk membuka halaman Detail Event. Halaman ini menampilkan informasi lengkap mengenai event yang dipilih.

    Informasi yang ditampilkan meliputi:

    - **Nama Event:** Menampilkan nama kegiatan atau hari libur, seperti Hari Tahun Baru.
    - **Instansi:** Menampilkan nama instansi atau sekolah yang menyelenggarakan event.
    - **Tanggal Event:** Menampilkan tanggal pelaksanaan event.
    - **Deskripsi Event:** Menampilkan keterangan atau informasi tambahan mengenai event tersebut.

    <Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1793240645505-kvz8u6vv8c-pasted-image-1793240642075.png?fm=auto&auto=compress%2Cformat" width="339" height="759" alt="" style="width: 339px; height: auto; cursor: pointer;" />
  </Step>
</Steps>

Halaman **Detail Event** menampilkan nama event, **Instansi**, **Tanggal Event**, dan **Deskripsi Event**. Untuk event non-libur tersedia tombol **Tambahkan ke Kalender** yang menyimpan event ke aplikasi kalender di HP Anda (memerlukan izin akses kalender).

<Callout kind="info" collapsed="false">
  Tampilan kalender mengikuti pengaturan lembaga, misalnya awal pekan (Senin/Ahad) dan hari Sabtu libur atau tidak.
</Callout>

## Rapor Siswa

Setelah langkah ini, Anda melihat file rapor siswa yang diunggah oleh Guru.

<Steps>
  <Step title="Buka menu Akademik" title-type="p">
    Tekan menu **Akademik**.


  </Step>

  <Step title="Pilih Rapor Siswa" title-type="p">
    Tekan sub menu **Rapor Siswa**.
  </Step>

  <Step title="Lihat file rapor" title-type="p">
    File rapor yang diunggah oleh Guru akan terlihat.
  </Step>
</Steps>

### Informasi yang ditampilkan

Setiap rapor pada **List Rapor** menampilkan kelas (mis. _Rapor Kelas VII - A_), tanggal unggah, badge **semester**, dan **Tahun Ajaran**. Menekan rapor akan membuka file rapor dalam bentuk **PDF** di dalam aplikasi.

<Callout kind="info" collapsed="false">
  Jika masih kosong, berarti rapor belum diunggah oleh Guru/Wali Kelas terkait. Pengelolaan rapor dilakukan oleh pihak sekolah melalui [CARDS School](/cards-school/tentang).
</Callout>

<Callout kind="alert" collapsed="false">
  Akses rapor dapat **dibatasi sementara** oleh sekolah. Jika demikian, aplikasi menampilkan pesan _Akses rapor sementara dibatasi_, umumnya karena tagihan belum lunas: _"Mohon lunasi tagihan terlebih dahulu untuk melihat rapor, silahkan hubungi Admin."_
</Callout>
