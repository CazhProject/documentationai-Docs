# Info Akun

Admin memiliki kemampuan untuk melihat info akun,

Langkah untuk melihat info akun :

1. Login ke website, kemudian klik submenu **Profile.**
2. Kemudian klik menu **Profile.**
   <Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1785833561102-2hlrrwbq4xr-pasted-image-1785833559984.png?fm=auto&auto=compress%2Cformat" width="1918" height="967" alt="" />
3. System akan menampilkan Halaman **Profile.**
4. Klik **Info akun.**
   <Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1785833605291-pe0is67peoj-pasted-image-1785833604501.png?fm=auto&auto=compress%2Cformat" width="1918" height="970" alt="" />
5. Pada halaman Info akun, Admin dapat :
   1. Mendapatkan nama.
   2. Mendapatkan alamat.
   3. Mendapatkan email.
   4. mendapatkan no.

<Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1785833628435-ppwpf7hcwpl-pasted-image-1785833627176.png?fm=auto&auto=compress%2Cformat" width="1919" height="966" alt="" />

Langkah untuk aktifk dan nonaktif support access :

2. Kemudian klik menu **Profile.**
   <Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1785833561102-2hlrrwbq4xr-pasted-image-1785833559984.png?fm=auto&auto=compress%2Cformat" width="1918" height="967" alt="" />

# Tema Dark/Light Mode

Admin memiliki kemampuan untuk mengganti tema gelap/terang,

Langkah untuk mengganti tema gelap/terang :

1. Login ke website, kemudian klik submenu **Profile.**
2. Pada **halaman Tema,&#x20;**&#x41;dmin dapat :
   1. Mengganti tema menjad&#x69;**&#x20;gelap/terang.**
3. Kemudian klik button kanan **Tema gelap.**
4. System akan menampilkan Halaman menjadi **Tema gelap.**
