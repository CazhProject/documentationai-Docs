# Bantuan - Hubungi CS

Admin memiliki kemampuan untuk menghubungi CS,

Langkah untuk Menghubungi CS:

1. Login ke website, kemudian klik menu **Hubungi CS.**
   <Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1785835082607-mahkkokb8y-pasted-image-1785835081697.png?fm=auto&auto=compress%2Cformat" width="1918" height="967" alt="" />
2. System akan redirect ke halaman cs dan menampilkan form untuk bertanya, atau bisa pilih pertanyaan yang sudah ada.
3. Pada halaman CS, Admin dapat bertanya kepada CS.
