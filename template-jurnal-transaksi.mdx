**List Template Jurnal Transaksi**

Halaman **Template Jurnal Transaksi** digunakan untuk melihat daftar seluruh template jurnal transaksi milik partner yang terdaftar pada sistem beserta informasi posisi debit dan kreditnya.

[https://drive.google.com/file/d/1Wwv861O1FY6v8KB2sHjYOsr2wPtnt0GZ/view?usp=drive\_link](https://drive.google.com/file/d/1Wwv861O1FY6v8KB2sHjYOsr2wPtnt0GZ/view?usp=drive_link)

1. **Buka menu Template Jurnal Transaksi**

Pada sidebar sebelah kiri, klik **Pengaturan → Pembukuan → Jurnal → Template Jurnal Transaksi**.

<Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1785127092062-p0lzus1sh2-list-jurnal-T-transaksi.png?fm=auto&auto=compress%2Cformat" width="1363" height="689" alt="" />

2. **Lihat daftar data Template Jurnal Transaksi**

Sistem akan menampilkan tabel daftar template jurnal transaksi beserta kolom **Nama Akun**, **Posisi Debit**, **Posisi Kredit**, dan **Aksi**.

<Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1785127154895-kntlzjy0am-list-data-jurnal-T-transaksi.png?fm=auto&auto=compress%2Cformat" width="1366" height="681" alt="" />

3. **Cari data Template Jurnal Transaksi**

Ketik kata kunci nama template pada kolom **Cari** di sudut kanan atas tabel untuk menemukan data secara spesifik.

<Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1785127234706-op6ve2qtzf-search-jurnal-T--transaksi.png?fm=auto&auto=compress%2Cformat" width="1366" height="681" alt="" />

**Tambah Template Jurnal Transaksi**

Fitur **Tambah Template Jurnal Transaksi** digunakan untuk menambahkan pola pencatatan jurnal transaksi baru ke dalam sistem.

[https://drive.google.com/file/d/1F\_SINFY08\_nuqAC8FMSBZe1vK4LAv3Qi/view?usp=drive\_link](https://drive.google.com/file/d/1F_SINFY08_nuqAC8FMSBZe1vK4LAv3Qi/view?usp=drive_link)

1. **Buka menu Template Jurnal Transaksi**

Pada sidebar sebelah kiri, klik **Pengaturan → Pembukuan → Jurnal → Template Jurnal Transaksi**.

<Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1785127092062-p0lzus1sh2-list-jurnal-T-transaksi.png?fm=auto&auto=compress%2Cformat" width="1363" height="689" alt="" />

2. **Klik tombol Tambah Jurnal Transaksi**

Pada halaman utama **Template Jurnal Transaksi**, klik tombol **+ Tambah Jurnal Transaksi** di sudut kanan atas.

<Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1785127378326-1dsbmflzfd8-tambah-jurnal-T-transaksi.png?fm=auto&auto=compress%2Cformat" width="1366" height="681" alt="" />

3. **Isi formulir Tambah Jurnal Transaksi**

Lengkapi kolom informasi yang tersedia:

- **Kode:** Ketik kode unik transaksi.
- **Nama:** Ketik nama template jurnal transaksi.
- **Akun Debit:** Pilih akun yang diposisikan sebagai Debit.
- **Akun Kredit:** Pilih akun yang diposisikan sebagai Kredit.

<Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1785127471848-tb5rihclx9a-tambah-data-jurnal-T--transaksi.png?fm=auto&auto=compress%2Cformat" width="1366" height="675" alt="" />

4. **Simpan data Template Jurnal Transaksi**

Klik tombol **Simpan** untuk memasukkan data template jurnal transaksi baru ke dalam sistem.

<Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1785127529075-220bb0fwigj-simpan-tambah-data-jurnal-T-transaksi.png?fm=auto&auto=compress%2Cformat" width="1366" height="675" alt="" />

**Edit Template Jurnal Transaksi**

Fitur **Edit Template Jurnal Transaksi** digunakan untuk memperbarui atau mengubah informasi template jurnal transaksi yang sudah terdaftar.

[https://drive.google.com/file/d/1emgsfmXwmA7bnH1HZtlu73YwNvlJff0W/view?usp=sharing](https://drive.google.com/file/d/1emgsfmXwmA7bnH1HZtlu73YwNvlJff0W/view?usp=sharing)

1. **Buka menu Template Jurnal Transaksi**

Pada sidebar sebelah kiri, klik **Pengaturan → Pembukuan → Jurnal → Template Jurnal Transaksi**.

<Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1785127092062-p0lzus1sh2-list-jurnal-T-transaksi.png?fm=auto&auto=compress%2Cformat" width="1363" height="689" alt="" />

2. **Pilih data yang akan diubah**

Pada tabel **Template Jurnal Transaksi**, cari template yang ingin diperbarui, lalu klik ikon **Edit** (pensil) pada kolom **Aksi**.

<Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1785127701532-sc4eiql2u0g-edit-jurnal-T-transaksi.png?fm=auto&auto=compress%2Cformat" width="1366" height="681" alt="" />

3. **Perbarui data Template Jurnal Transaksi**

Ubah informasi pada formulir **Ubah Jurnal Transaksi** sesuai kebutuhan Anda.

<Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1785127768985-i4fc9n93uc-edit-data-jurnal-T-transaksi.png?fm=auto&auto=compress%2Cformat" width="1366" height="672" alt="" />

4. **Simpan perubahan data**

Klik tombol **Simpan** untuk memperbarui data template jurnal transaksi pada sistem.

<Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1785127831103-00gw0i5mr99b7-simapan-edit-data-jurnal-transaksi.png?fm=auto&auto=compress%2Cformat" width="1366" height="672" alt="" />

**Hapus Template Jurnal Transaksi**

Fitur **Hapus Template Jurnal Transaksi** digunakan untuk menghapus template jurnal transaksi yang sudah tidak digunakan dari sistem.

[https://drive.google.com/file/d/1OS\_g7ziHRkXg9zWO2Cg47I1RuXmic0h6/view?usp=drive\_link](https://drive.google.com/file/d/1OS_g7ziHRkXg9zWO2Cg47I1RuXmic0h6/view?usp=drive_link)

1. **Buka menu Template Jurnal Transaksi**

Pada sidebar sebelah kiri, klik **Pengaturan → Pembukuan → Jurnal → Template Jurnal Transaksi**.

<Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1785127092062-p0lzus1sh2-list-jurnal-T-transaksi.png?fm=auto&auto=compress%2Cformat" width="1363" height="689" alt="" />

2. **Pilih data yang akan dihapus**

Pada tabel **Template Jurnal Transaksi**, cari template yang ingin dihapus, lalu klik ikon **Hapus** (tempat sampah) pada kolom **Aksi**.

<Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1785128017531-10o02h75xtya-hapus-jurnal-T-Transaksi.png?fm=auto&auto=compress%2Cformat" width="1366" height="681" alt="" />

3. **Konfirmasi penghapusan data**

Pada jendela modal **Hapus Data** yang muncul, klik tombol **Hapus** untuk menghapus data secara permanen.

<Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1785128076730-nonzz6yvtqj-hapus-data-jurnal-transaksi.png?fm=auto&auto=compress%2Cformat" width="1366" height="687" alt="" />
