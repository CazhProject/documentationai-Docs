Menu **Template Jurnal Sistem** digunakan untuk mengatur pemetaan akun debit dan kredit pada jurnal otomatis bawaan sistem. Admin dapat melihat daftar template jurnal sistem serta mengubah pemetaan akun debit dan kredit yang digunakan.

<Callout kind="alert" collapsed="false">
  Pastikan Anda sudah login sebagai Admin dan memiliki hak akses ke menu Pengaturan → Pembukuan → Jurnal → Template Jurnal Sistem.
</Callout>

**List Template Jurnal Sistem**

Halaman **Template Jurnal Sistem** digunakan untuk melihat daftar seluruh template jurnal bawaan sistem beserta informasi akun posisi debit dan kreditnya.

link dokumentasi

1. **Buka menu Template Jurnal Sistem**

Pada sidebar sebelah kiri, klik **Pengaturan → Pembukuan → Jurnal → Template Jurnal Sistem**.

<Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1785129330245-ln8q7e2yn4c-list-template-jurnal.png?fm=auto&auto=compress%2Cformat" width="1366" height="682" alt="" />

2. **Lihat daftar data Template Jurnal Sistem**

Sistem akan menampilkan tabel daftar template jurnal sistem beserta kolom **Nama Akun**, **Posisi Debit**, **Posisi Kredit**, dan **Aksi**.

<Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1785129434432-j27a9xht2ie-list-data-jurnal-sistem.png?fm=auto&auto=compress%2Cformat" width="1403" height="713" alt="" />

3. **Cari data Template Jurnal Sistem**

Ketik kata kunci nama akun atau transaksi pada kolom **Cari** di sudut kanan atas tabel untuk menemukan data secara spesifik.

<Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1785129504475-493o5bn7dx2-search-jurnal-sistem.png?fm=auto&auto=compress%2Cformat" width="1403" height="713" alt="" />

**Edit Template Jurnal Sistem**

Fitur **Edit Template Jurnal Sistem** digunakan untuk memperbarui atau menyesuaikan pemetaan akun debit dan kredit pada template jurnal sistem yang ada.

link dokumentasi

1. **Buka menu Template Jurnal Sistem**

Pada sidebar sebelah kiri, klik **Pengaturan → Pembukuan → Jurnal → Template Jurnal Sistem**.

<Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1785129330245-ln8q7e2yn4c-list-template-jurnal.png?fm=auto&auto=compress%2Cformat" width="1366" height="682" alt="" />

2. **Pilih data yang akan diubah**

Pada tabel **Template Jurnal Sistem**, cari template yang ingin diperbarui, lalu klik ikon **Edit** (pensil) pada kolom **Aksi**.

<Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1785129653185-v5aixmkhoz-edit-jurnal-sistem.png?fm=auto&auto=compress%2Cformat" width="1403" height="713" alt="" />

3. **Perbarui data Template Jurnal Sistem**

Pada halaman **Ubah Jurnal Sistem**, sesuaikan kolom informasi berikut:

- **Kode:** Kode transaksi bawaan sistem.
- **Nama:** Nama transaksi jurnal sistem.
- **Akun Debit:** Pilih akun General Ledger yang diposisikan sebagai Debit.
- **Akun Kredit:** Pilih akun General Ledger yang diposisikan sebagai Kredit.

<Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1785129716647-hnlr63shund-edit-data-jurnal-sistem.png?fm=auto&auto=compress%2Cformat" width="1403" height="713" alt="" />

4. **Simpan perubahan data**

Klik tombol **Simpan** untuk memperbarui pemetaan akun pada jurnal sistem.

<Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1785129835253-9vlb8wae3dn-simpan-edit-data-jurnal-sistem.png?fm=auto&auto=compress%2Cformat" width="1403" height="713" alt="" />
