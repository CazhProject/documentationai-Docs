  sistem. Admin dapat melihat daftar pos akun, menambahkan pos akun baru, serta

<Callout kind="alert" collapsed="false">
  Pastikan Anda sudah login sebagai Admin dan memiliki hak akses ke menu **Pengaturan → Pembukuan → Pos Akun**.
</Callout>

**List Pos Akun**

Halaman Pos Akun digunakan untuk melihat daftar pos akun yang telah dibuat pada sistem. Admin dapat mencari data pos akun serta mengakses fitur untuk menambah, mengubah, menghapus, menyaring, mengekspor, atau mengimpor data pos akun.

link dokumentasi

1. **Buka menu Pos Akun**

Pada sidebar, klik **Pengaturan → Pembukuan → Pos Akun**.

<Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1786294729940-58kr8dgrjti-list-pos-akun.png?fm=auto&auto=compress%2Cformat" width="1403" height="713" alt="" />

2. **Lihat daftar Pos Akun**

Sistem menampilkan daftar pos akun beserta informasi **Nama Pos**, dan kolom **Aksi**.

<Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1786294903492-lnvy2uyawt8-Untitledist-data-pos-akun.png?fm=auto&auto=compress%2Cformat" width="1403" height="713" alt="" />

3. **Cari data Pos Akun**

Gunakan kolom **Cari** untuk menemukan data pos akun berdasarkan kata kunci nama pos yang diinginkan.

<Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1786295002929-htu873lnbsu-search-pos-akun.png?fm=auto&auto=compress%2Cformat" width="1403" height="713" alt="" />

**Tambah Pos Akun**

Halaman ini digunakan untuk menambahkan data pos akun baru ke dalam sistem.

link dokumentasi

1. **Buka menu Pos Akun**

Pada sidebar, klik **Pengaturan → Pembukuan → Pos Akun**.

<Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1786294729940-58kr8dgrjti-list-pos-akun.png?fm=auto&auto=compress%2Cformat" width="1403" height="713" alt="" />

2. **Klik tombol Tambah Pos Akun**

Pada halaman Pos Akun, klik tombol **+ Tambah Pos Akun** yang terletak di pojok kanan atas.

<Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1786295175726-1yrf1lp8arg-tambah-pos-akun.png?fm=auto&auto=compress%2Cformat" width="1403" height="713" alt="" style="width: 1403px; height: auto; cursor: pointer;" />

3. **Isi formulir Tambah Pos Akun**

Masukkan **Nama Pos** (contoh: _Kas & Bank_) pada kolom yang tersedia, lalu klik tombol **Simpan**.

<Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1786295694985-w7afm1zyv8f-tambah-data-pos-akun.png?fm=auto&auto=compress%2Cformat" width="1403" height="713" alt="" />

4. **Edit Pos Akun**

Halaman ini digunakan untuk mengubah atau memperbarui data pos akun yang sudah ada di dalam sistem.

link dokumentasi

1. **Buka menu Pos Akun**

Pada sidebar, klik **Pengaturan → Pembukuan → Pos Akun**.

<Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1786294729940-58kr8dgrjti-list-pos-akun.png?fm=auto&auto=compress%2Cformat" width="1403" height="713" alt="" />

2. **Pilih data dan klik ikon Edit**

Pada tabel Pos Akun, cari data yang ingin diubah, lalu klik ikon **Edit** (pensil) pada kolom **Aksi**.

<Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1786295965924-wbn2t1mfand-edit-pos-akun.png?fm=auto&auto=compress%2Cformat" width="1403" height="713" alt="" />

3. **Ubah data Pos Akun**

Perbarui **Nama Pos** pada kolom yang tersedia, lalu klik tombol **Simpan**.

<Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1786296095966-ro4fq7n4bxb-edit-data-pos-akun.png?fm=auto&auto=compress%2Cformat" width="1403" height="713" alt="" />

**Hapus Pos Akun**

Halaman ini digunakan untuk menghapus data pos akun yang sudah tidak digunakan di dalam sistem.

link dokumentasi

1. **Buka menu Pos Akun**

Pada sidebar, klik **Pengaturan → Pembukuan → Pos Akun**.

<Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1786294729940-58kr8dgrjti-list-pos-akun.png?fm=auto&auto=compress%2Cformat" width="1403" height="713" alt="" />

2. **Pilih data dan klik ikon Hapus**

Pada tabel Pos Akun, cari data yang ingin dihapus, lalu klik ikon **Hapus** (tempat sampah) pada kolom **Aksi**.

<Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1786296330293-lq4ke1w7qgd-hapus-pos-akun.png?fm=auto&auto=compress%2Cformat" width="1403" height="713" alt="" />

3. **Konfirmasi hapus data**

Pada pop-up konfirmasi **Hapus Data**, klik tombol **Hapus** berwarna merah untuk menghapus data secara permanen.

<Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1786296465416-81lnzoejokv-hapus-data-pos-akun.png?fm=auto&auto=compress%2Cformat" width="1403" height="713" alt="" />

**Export Pos Akun**

Halaman ini digunakan untuk mengunduh rekap data pos akun yang terdaftar di dalam sistem ke dalam format file Excel (.xlsx).

link dokumentasi

1. **Buka menu Pos Akun**

Pada sidebar, klik **Pengaturan → Pembukuan → Pos Akun**.

<Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1786294729940-58kr8dgrjti-list-pos-akun.png?fm=auto&auto=compress%2Cformat" width="1403" height="713" alt="" />

2. **Klik tombol Export**

Pada bagian kanan atas halaman Pos Akun, klik tombol **Export**.

<Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1786296790943-thkx37lsds-export-pos-akun.png?fm=auto&auto=compress%2Cformat" width="1403" height="713" alt="" />

3. **Unduh file data Pos Akun**

Sistem akan memproses data secara otomatis dan mengunduh file spreadsheet ke perangkat

**Import Pos Akun**

Halaman ini digunakan untuk mengunggah atau menambahkan data pos akun secara massal ke dalam sistem menggunakan file spreadsheet (.xlsx / .xls).

link dokumentasi

1. **Buka menu Pos Akun**

Pada sidebar, klik **Pengaturan → Pembukuan → Pos Akun**.

<Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1786294729940-58kr8dgrjti-list-pos-akun.png?fm=auto&auto=compress%2Cformat" width="1403" height="713" alt="" />

2. **Klik tombol Import**

Pada bagian kanan atas halaman Pos Akun, klik tombol **Import**.

<Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1786297218519-zbsfi3spct-import-pos-akun.png?fm=auto&auto=compress%2Cformat" width="1403" height="713" alt="" />

3. **Unduh Template Pos Akun&#x20;**

Pada pop-up **Import Data**, Anda dapat mengunduh contoh format file dengan mengeklik tombol **Download** pada bagian _Template Pos Akun_. Pastikan isi file sesuai dengan ketentuan kolom yang dibutuhkan (kolom: `nama`).

<Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1786297355107-1vqvk6iqk07-donwload-import-pos-akun.png?fm=auto&auto=compress%2Cformat" width="1403" height="713" alt="" />

4. **Unggah file dan klik Import**

- Klik area **Pilih File** untuk memilih file spreadsheet dari perangkat Anda (format file `.xlsx` atau `.xls`, ukuran maksimal 5 MB).
- Setelah file terpilih, klik tombol **Import** berwarna biru untuk memproses penyimpanan data secara massal ke dalam sistem.

<Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1786297476566-585uo228ezg-isi-data-import-pos-akun.png?fm=auto&auto=compress%2Cformat" width="1403" height="713" alt="" />
