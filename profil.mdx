# Info Akun

Admin memiliki kemampuan untuk melihat info akun,

Langkah untuk melihat info akun :

1. Login ke website, kemudian klik submenu **Profile.**
2. Kemudian klik menu **Profile.**
   <Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1785833561102-2hlrrwbq4xr-pasted-image-1785833559984.png?fm=auto&auto=compress%2Cformat" width="1918" height="967" alt="" />
3. System akan menampilkan Halaman **Profile.**
4. Klik **Info akun.**
   <Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1785833605291-pe0is67peoj-pasted-image-1785833604501.png?fm=auto&auto=compress%2Cformat" width="1918" height="970" alt="" />
5. Pada halaman Info akun, Admin dapat :
   1. Mendapatkan nama.
   2. Mendapatkan alamat.
   3. Mendapatkan email.
   4. mendapatkan no.

<Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1785833628435-ppwpf7hcwpl-pasted-image-1785833627176.png?fm=auto&auto=compress%2Cformat" width="1919" height="966" alt="" />

# Support Access

Langkah untuk aktifk dan nonaktif support access :

1. Login ke website, kemudian klik submenu **Profile.**
2. Kemudian klik menu **Profile.**
   <Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1785833561102-2hlrrwbq4xr-pasted-image-1785833559984.png?fm=auto&auto=compress%2Cformat" width="1918" height="967" alt="" />

# Akun Terhubung

Halaman Aktivitas Login digunakan untuk melihat daftar perangkat yang mengakses akun. Informasi yang ditampilkan meliputi tipe perangkat atau browser, perkiraan lokasi, dan waktu akses terakhir. Pengguna dapat memeriksa aktivitas login untuk mengenali perangkat yang sedang atau pernah mengakses akun.

**Link Video:&#xA0;**[**https://drive.google.com/file/d/1PS0DATvoUiG301e6Q7MNuOabIMiHrY\_d/view?usp=drive\_link**](https://drive.google.com/file/d/1PS0DATvoUiG301e6Q7MNuOabIMiHrY_d/view?usp=drive_link)

Langkah langkah nya sebagai berikut :

<Steps>
  <Step title="Login dan Buka Menu Profil" title-type="p">
    Login ke website CARDS School menggunakan akun Admin, kemudian klik ikon profil di pojok kanan atas dan pilih menu **Profil**.

    <Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1792568573360-2wfqpm8owyb-pasted-image-1792568566185.png?fm=auto&auto=compress%2Cformat" width="1363" height="632" alt="" />
  </Step>

  <Step title="Buka Menu Aktivitas Login" title-type="p">
    Setelah halaman Profil terbuka, klik tab **Aktivitas Login** untuk melihat informasi riwayat aktivitas login akun.

    <Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1792569171100-n4hsib7t0j-pasted-image-1792569164945.png?fm=auto&auto=compress%2Cformat" width="1361" height="628" alt="" />
  </Step>

  <Step title="Melihat Aktivitas Login" title-type="p">
    Sistem menampilkan daftar aktivitas login yang berisi tipe perangkat atau browser, perkiraan lokasi, dan waktu akses terakhir (_Last Access_). Perangkat yang sedang digunakan ditandai dengan label **Perangkat Saat Ini**. Pengguna dapat memeriksa daftar tersebut untuk mengenali aktivitas login pada akunnya.

    <Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1792569301950-8pr56pwn3sh-pasted-image-1792569295774.png?fm=auto&auto=compress%2Cformat" width="1361" height="632" alt="" />
  </Step>
</Steps>

# Tema Dark/Light Mode

Admin memiliki kemampuan untuk mengganti tema gelap/terang,

Langkah untuk mengganti tema gelap/terang :

1. Login ke website, kemudian klik submenu **Profile.**
2. Pada **halaman Tema,&#x20;**&#x41;dmin dapat :
   1. Mengganti tema menjad&#x69;**&#x20;gelap/terang.**
3. Kemudian klik button kanan **Tema gelap.**
4. System akan menampilkan Halaman menjadi **Tema gelap.**
