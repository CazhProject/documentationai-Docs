<Callout kind="info" collapsed="false">
  Data kesiswaan juga dapat diakses melalui aplikasi. Lihat [Kesiswaan di CARDS Edu](/cards-edu/kesiswaan).
</Callout>

## List Prestasi

### Informasi yang ditampilkan

Tabel Prestasi menampilkan kolom: **Tanggal Kejadian**, **Siswa**, **Kategori Prestasi**, **Deskripsi**, **Apresiasi**, **Poin**, **Foto**, dan **Dibuat Oleh**. Export Excel menghasilkan sheet **Prestasi**.

Cara Penggunaan:

<Steps>
  <Step title="Buka menu Kesiswaan" title-type="p">
    Login menggunakan akun Admin, lalu klik menu **Kesiswaan**.
  </Step>

  <Step title="Buka Prestasi" title-type="p">
    Pilih submenu **Prestasi**. Sistem menampilkan halaman prestasi siswa.\
    Pada halaman tersebut, Admin dapat:\
    a. Melihat data prestasi siswa.\
    b. Melakukan pencarian data prestasi.\
    c. Mengekspor data prestasi siswa.\

  </Step>
</Steps>

## Tambah Prestasi

Admin dapat menambahkan informasi prestasi siswa ke dalam sistem melalui menu Prestasi.

Proses Penambahan Data:

<Steps>
  <Step title="Buka Prestasi" title-type="p">
    Login menggunakan akun Admin, buka menu Kesiswaan, lalu pilih submenu Prestasi. Sistem menampilkan halaman prestasi siswa.
  </Step>

  <Step title="Buka form tambah" title-type="p">
    Klik tombol Tambah Prestasi.\


    <Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1785086393276-q6xxifrofl-Prestasi---Tambah.Prestasi - Tambah?fm=auto&auto=compress%2Cformat" width="1920" height="1080" alt="" />
  </Step>

  <Step title="Isi formulir" title-type="p">
    Lengkapi formulir prestasi siswa sesuai kebutuhan.
  </Step>

  <Step title="Simpan" title-type="p">
    Klik tombol Simpan untuk menyimpan data prestasi siswa.
  </Step>
</Steps>

\
Vidio Tutorial:\
[https://drive.google.com/file/d/1k1McFXrfVryisdXUOXGu0anIHpqMtFZX/view?usp=sharing](https://drive.google.com/file/d/1k1McFXrfVryisdXUOXGu0anIHpqMtFZX/view?usp=sharing)

### Isian formulir

| Isian               | Ketentuan                                                |
| ------------------- | -------------------------------------------------------- |
| Anggota (siswa)     | Wajib.                                                   |
| Tanggal             | Wajib, format tanggal.                                   |
| Kategori            | Wajib, teks bebas, maksimal 255 karakter.                |
| Deskripsi/Kronologi | Wajib.                                                   |
| Apresiasi           | Wajib, maksimal 255 karakter.                            |
| Poin                | Wajib, angka.                                            |
| Foto                | Opsional, gambar png/jpg/jpeg/heic/heif, maksimal 10 MB. |

<Callout kind="info" collapsed="false">
  Setiap pencatatan prestasi otomatis menambahkan catatan poin (point log) pada siswa sesuai kategori dan poin yang diisi.
</Callout>

## Edit Prestasi

Admin dapat memperbarui informasi prestasi siswa  yang sudah tercatat melalui menu Prestasi.

Langkah Edit:

<Steps>
  <Step title="Buka Prestasi" title-type="p">
    Login menggunakan akun Admin, masuk ke menu Kesiswaan, lalu pilih submenu Prestasi. Sistem menampilkan halaman prestasi siswa.
  </Step>

  <Step title="Pilih data" title-type="p">
    Tentukan data prestasi yang akan diperbarui, lalu klik tombol Edit Prestasi.\


    <Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1785086507958-z7wzdx3r3zm-Prestasi---Edit.Prestasi - Edit?fm=auto&auto=compress%2Cformat" width="1920" height="1080" alt="" />
  </Step>

  <Step title="Ubah data" title-type="p">
    Ubah data prestasi sesuai kebutuhan.
  </Step>

  <Step title="Simpan" title-type="p">
    Klik tombol Simpan untuk menyimpan perubahan data prestasi siswa.
  </Step>
</Steps>

## Hapus Prestasi

Hapus data prestasi siswa dari sistem. Prestasi adalah catatan pencapaian siswa (kategori, apresiasi, dan poin) yang tercatat di sistem. Data yang dihapus tidak lagi tampil di daftar prestasi. Aksi ini biasanya dipakai saat data salah input atau duplikat.

Proses Penghapusan Data:

<Steps>
  <Step title="Buka Prestasi" title-type="p">
    Login menggunakan akun Admin, buka menu **Kesiswaan**, lalu pilih submenu **Prestasi**. Sistem menampilkan halaman prestasi siswa.
  </Step>

  <Step title="Pilih data" title-type="p">
    Pilih data prestasi yang ingin dihapus, lalu klik tombol **Hapus Prestasi**.\


    <Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1785086574547-odhf3a66yk-Prestasi---Hapus.Prestasi - Hapus?fm=auto&auto=compress%2Cformat" width="1920" height="1080" alt="" />
  </Step>

  <Step title="Konfirmasi" title-type="p">
    Klik tombol **Hapus** untuk mengonfirmasi proses penghapusan data prestasi.
  </Step>
</Steps>

\
