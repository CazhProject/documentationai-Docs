Menu Donasi digunakan admin sekolah untuk mengelola program donasi instansi: membuat, mengubah, menghapus, dan memantau donatur. Terdapat tiga jenis program donasi:

| Jenis                              | Keterangan                         | Tab                   |
| ---------------------------------- | ---------------------------------- | --------------------- |
| **Donasi Umum**                    | Donasi tanpa target dana.          | **Donasi Umum**       |
| **Donasi Penggalangan Dana**       | Donasi dengan target dana.         | **Penggalangan Dana** |
| **Donasi Khusus** (Program Khusus) | Donasi berbasis kuota dan nominal. | **Donasi Khusus**     |

## Daftar Donasi

1. **Login ke Website lalu akses menu Administrasi**
2. **Pilih sub menu Donasi**
3. **Halaman akan menampilkan daftar donasi, pilih daftar donasi yang ingin ditampilkan&#x20;**

### Informasi yang ditampilkan

Kolom daftar donasi menyesuaikan jenis program:

| Tab               | Kolom                                                                              |
| ----------------- | ---------------------------------------------------------------------------------- |
| Umum              | Instansi, Program, Cakupan, Terkumpul, Mulai, Selesai                              |
| Penggalangan Dana | Instansi, Program, Cakupan, Dana Target, Terkumpul, Mulai, Selesai                 |
| Khusus            | Instansi, Program, Cakupan, Dana Target, Terkumpul, Kuota, Nominal, Mulai, Selesai |

Daftar diurutkan berdasarkan tanggal selesai terbaru. Export Excel menghasilkan file **Donasi - Umum**, **Donasi - Penggalangan Dana**, atau **Donasi - Program Khusus** sesuai tab aktif.

## Tambah Donasi

1. **Login ke Website lalu akses menu Administrasi**
2. **Pilih sub menu Donasi**
3. **Halaman akan menampilkan daftar donasi, pilih button dikanan atas "Tambah Program Donasi" untuk menambahkan donasi**
4. **Isikan semua formulir sesuai dengan kebutuhan dan ketentuan sebagai berikut:**

| Isian                     | Ketentuan                                                                              |
| ------------------------- | -------------------------------------------------------------------------------------- |
| Instansi                  | Wajib.                                                                                 |
| Judul Program             | Wajib (contoh: "Pembangunan Masjid").                                                  |
| Jenis Program             | Wajib: Umum, Penggalangan Dana, atau Program Khusus.                                   |
| Cakupan Donasi            | Wajib, dapat memilih lebih dari satu: **Internal** dan/atau **Eksternal**.             |
| Dana Target               | Khusus jenis Penggalangan Dana; minimal Rp 10.000.                                     |
| Kuota                     | Khusus jenis Program Khusus; wajib, angka.                                             |
| Nominal                   | Khusus jenis Program Khusus; wajib, minimal Rp 10.000. Total target = nominal × kuota. |
| Periode (Mulai & Selesai) | Wajib; tanggal selesai harus setelah tanggal mulai.                                    |
| Deskripsi                 | Wajib.                                                                                 |
| Thumbnail                 | Opsional, gambar jpg/png/jpeg/heic/heif, maksimal 10 MB.                               |

5. **Apabila semua sudah terisi dan benar, klik simpan**
6. **Akan muncul pop up bahwa donasi telah berhasil dibuat dan masuk daftar donasi**

## Edit Donasi

1. **Login ke Website lalu akses menu Administrasi**
2. **Pilih sub menu Donasi**
3. **Halaman akan menampilkan daftar donasi, pilih salah satu donasi lalu klik titik 3 disamping**
4. **Pilih opsi "edit"**
5. **Akan dialihkan ke halaman edit, silahkan edit bagian yang ingin di edit**
6. **Klik simpan apabila sudah selesai**
7. **Akan muncul pop up bahwa data donasi telah berhasil di edit**

## Hapus Donasi

1. **Login ke Website lalu akses menu Administrasi**
2. **Pilih sub menu Donasi**
3. **Halaman akan menampilkan daftar donasi, pilih salah satu donasi lalu klik titik 3 disamping**
4. **Pilih opsi "hapus"**
5. **Akan muncul warning pop up, klik "hapus" untuk melanjutkan**
6. **Data donasi berhasil dihapus**

## Detail Donasi Umum

Memonitor data donatur pada donasi umum.

1. **Login ke Website lalu akses menu Administrasi**
2. **Pilih sub menu Donasi**
3. **Halaman akan menampilkan daftar donasi, lalu pilih jenis donasi yang ingin ditampilkan di list**
4. **Halaman akan menampilkan daftar donasi umum**
5. **Untuk export ke excel, klik button excel yang ada di pojok kanan**
6. **Untuk melihat detail dari data donasi, pilih salah satu data donasi lalu klik titik tiga di samping**
7. **Pilih opsi detail**

### Informasi yang ditampilkan

Daftar donatur menampilkan kolom: **Nama Donatur**, **Email**, **No HP**, **Alamat**, **Jumlah Donasi**, **Tanggal**, dan **Catatan**, diurutkan dari pembayaran terbaru. Export Excel menghasilkan file **Daftar Donatur**.

<Callout kind="info" collapsed="false">
  Daftar donatur hanya menampilkan donasi yang sudah berstatus **Lunas (terbayar)**; struk donatur juga hanya dapat dibuka untuk pembayaran yang sudah lunas.
</Callout>
