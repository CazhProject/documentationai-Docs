---
title: 'Keuangan: Donasi'
description: >-
  Panduan mengelola program donasi di CARDS School: daftar donasi, tambah, edit,
  hapus, serta detail donasi umum, penggalangan dana, dan donasi khusus.
---
Menu Donasi digunakan admin sekolah untuk mengelola program donasi instansi: membuat, mengubah, menghapus, dan memantau donatur. Terdapat tiga jenis program donasi:

| Jenis                              | Keterangan                         | Tab                   |
| ---------------------------------- | ---------------------------------- | --------------------- |
| **Donasi Umum**                    | Donasi tanpa target dana.          | **Donasi Umum**       |
| **Donasi Penggalangan Dana**       | Donasi dengan target dana.         | **Penggalangan Dana** |
| **Donasi Khusus** (Program Khusus) | Donasi berbasis kuota dan nominal. | **Donasi Khusus**     |

## Donasi Umum

**Link Video : &#x20;**[**https://drive.google.com/file/d/1lwKICxXONyz3qrGxAVwVOHze1cPkPu8q/view?usp=sharing**](https://drive.google.com/file/d/1lwKICxXONyz3qrGxAVwVOHze1cPkPu8q/view?usp=sharing)

1. **Login ke Website lalu akses menu Administrasi**
2. **Pilih sub menu Donasi**
3. **Halaman akan menampilkan daftar donasi, pilih daftar Donasi Umum**
4. **Untuk tambah data donasi, pilih button dikanan atas "Tambah Program Donasi"&#x20;**
5. **Pastikan jenis donasi yang dipilih adalah "Donasi Umum"**
6. **Apabila semua sudah terisi dan benar, klik simpan**
7. **Akan muncul pop up bahwa donasi telah berhasil dibuat dan masuk daftar donasi**
8. **Untuk edit data donasi, kembali ke halaman daftar donasi, lalu klik titik 3 di ujung kanan data donasi**
9. **Pilih opsi "edit"**
10. **Akan dialihkan ke halaman edit, silahkan edit bagian yang ingin di edit**
11. **Klik simpan apabila sudah selesai**
12. **Akan muncul pop up bahwa data donasi telah berhasil di edit**
13. **Untuk hapus data donasi, kembali ke halaman daftar donasi, lalu klik titik 3 di ujung kanan data donasi**
14. **Pilih opsi "hapus"**
15. **Akan muncul warning pop up, klik "hapus" untuk melanjutkan**
16. **Data donasi berhasil dihapus**
17. **Untuk melihat detail data donasi, kembali ke halaman daftar donasi, lalu klik titik 3 di ujung kanan data donasi**
18. **Pilih opsi detail**
19. **Maka halaman akan diarahkan ke halaman detail data donasi tersebut**
20. **Klik button excel untuk meng export data donasi tersebut**
