  Panduan mengelola program donasi di CARDS School: daftar donasi, tambah, edit,
  hapus, serta detail donasi umum, penggalangan dana, dan donasi khusus.
---
Menu Donasi digunakan admin sekolah untuk mengelola program donasi instansi: membuat, mengubah, menghapus, dan memantau donatur. Terdapat tiga jenis program donasi:

| Jenis                              | Keterangan                         | Tab                   |
| ---------------------------------- | ---------------------------------- | --------------------- |
| **Donasi Umum**                    | Donasi tanpa target dana.          | **Donasi Umum**       |
| **Donasi Penggalangan Dana**       | Donasi dengan target dana.         | **Penggalangan Dana** |
| **Donasi Khusus** (Program Khusus) | Donasi berbasis kuota dan nominal. | **Donasi Khusus**     |

## Donasi Umum

**Link Video : &#x20;**[**https://drive.google.com/file/d/1lwKICxXONyz3qrGxAVwVOHze1cPkPu8q/view?usp=sharing**](https://drive.google.com/file/d/1lwKICxXONyz3qrGxAVwVOHze1cPkPu8q/view?usp=sharing)

## List Donasi Umum

1. Login ke Website lalu akses menu Administrasi
2. Pilih sub menu Donasi
3. Halaman akan menampilkan daftar donasi, pilih daftar Donasi Umum
4. Klik button excel untuk meng export data donasi tersebut

## Tambah Program Donasi Umum

1. Untuk tambah data donasi, pilih button dikanan atas "Tambah Program Donasi"&#x20;
2. Pilih instansi program donasi
3. Lalu isikan jangkauan donasi yang akan dituju&#x20;
4. Isikan judul donasi
5. Pastikan jenis donasi yang dipilih adalah "Donasi Umum"
6. Dilanjutkan dengan mengisi waktu berjalannya donasi (tanggal mulai dan tanggal berakhir)
7. Isikan sub judul (opsional), foto (opsional), dan deskripsi donasi
8. Apabila semua sudah terisi dan benar, klik simpan
9. Akan muncul pop up bahwa donasi telah berhasil dibuat dan masuk daftar donasi

## Edit Data Program Donasi Umum

1. Untuk edit data donasi, kembali ke halaman daftar donasi, lalu klik titik 3 di ujung kanan data donasi
2. Pilih opsi "edit"
3. Akan dialihkan ke halaman edit, silahkan edit bagian yang ingin di edit
4. Klik simpan apabila sudah selesai
5. Akan muncul pop up bahwa data donasi telah berhasil di edit

## Hapus Data Program Donasi Umum

1. Untuk hapus data donasi, kembali ke halaman daftar donasi, lalu klik titik 3 di ujung kanan data donasi
2. Pilih opsi "hapus"
3. Akan muncul warning pop up, klik "hapus" untuk melanjutkan
4. Data donasi berhasil dihapus

## Detail Data Program Donasi Umum

1. Untuk melihat detail data donasi, kembali ke halaman daftar donasi, lalu klik titik 3 di ujung kanan data donasi
2. Pilih opsi detail
3. Maka halaman akan diarahkan ke halaman detail data donasi tersebut
