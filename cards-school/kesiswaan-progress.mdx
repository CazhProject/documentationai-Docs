## Edit Progress Kegiatan

<Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1785082532910-z1i9broxlw-Progres-Kegiatan---Edit.Progres Kegiatan - Edit?fm=auto&auto=compress%2Cformat" width="1920" height="1080" alt="" />

Perbarui data progress kegiatan yang sudah tercatat. Progress kegiatan adalah catatan perkembangan/capaian kegiatan siswa yang tercatat di sistem, aksi ini dipakai untuk memperbaiki data yang salah input tanpa menghapus riwayatnya.

Langkah Penggunaan:

1. Login menggunakan akun Admin.
2. Masuk ke menu **Kesiswaan.**
3. Pilih submenu **Progress Kegiatan.**
4. Sistem akan menampilkan halaman daftar progress kegiatan.
5. Tentukan data progress kegiatan yang akan diedit.
6. Klik opsi **Edit&#x20;**&#x70;ada data yang dipilih.
7. Isi form edit sesuai dengan kebutuhan.
8. Klik tombol **Simpan&#x20;**&#x75;ntuk menyimpan data yang telah diperbarui.\
   \
   Vidio Tutorial: [https://drive.google.com/file/d/1XV0MDOTrPwJfpx148bxjFzoid8hbMDcC/view?usp=sharing](https://drive.google.com/file/d/1XV0MDOTrPwJfpx148bxjFzoid8hbMDcC/view?usp=sharing)

## Hapus Progress Kegiatan

<Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1785083908942-9a6d6u2g0j-Progres-Kegiatan---Hapus.Progres Kegiatan - Hapus?fm=auto&auto=compress%2Cformat" width="1920" height="1080" alt="" />

Hapus data progress kegiatan siswa dari sistem. Progress kegiatan adalah catatan perkembangan/capaian kegiatan siswa beserta riwayat dan grafiknya. Data yang dihapus tidak lagi tampil di daftar progress kegiatan, termasuk saat data kesiswaan diakses melalui aplikasi CARDS Edu. Aksi ini biasanya dipakai saat data salah input atau duplikat.

<Callout kind="alert" collapsed="false">
  Penghapusan data progress kegiatan bersifat permanen dan tidak dapat dikembalikan.
</Callout>

Langkah Penggunaan:

1. Login menggunakan akun Admin.
2. Masuk ke menu **Kesiswaan.**
3. Pilih submenu **Progress Kegiatan.**
4. Sistem akan menampilkan halaman daftar progress kegiatan.
5. Tentukan data progress kegiatan yang akan dihapus.
6. Klik opsi **Hapus&#x20;**&#x70;ada data yang dipilih.
7. Sistem akan menampilkan konfirmasi penghapusan data.
8. Klik tombol **Hapus&#x20;**&#x75;ntuk melanjutkan proses penghapusan.\
   \
   Vidio Tutorial: [https://drive.google.com/file/d/1zR6EL3tNtSFP50\_ZLMnMtBKB9KgoyzMu/view?usp=sharing](https://drive.google.com/file/d/1zR6EL3tNtSFP50_ZLMnMtBKB9KgoyzMu/view?usp=sharing)

## Tambah Progress Kegiatan

<Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1785083652008-7gxwve7x9uj-Progres-Kegiatan---Tambah.Progres Kegiatan - Tambah?fm=auto&auto=compress%2Cformat" width="1920" height="1080" alt="" />

Tambahkan data progress kegiatan siswa baru ke dalam sistem, baik satu per satu maupun lewat import.

Cara Penggunaan:\
Login menggunakan akun Admin.

1. Pilih  menu **Kesiswaan**.
2. Pilih menu **Progress Kegiatan**.
3. Sistem akan menampilkan halaman progress kegiatan.
4. Klik opsi **Tambah Progress Kegiatan.**
5. Klik opsi **Tambah Progress Kegiatan.**
6. Klik opsi **Import Progress → Isi Form&#x20;**&#x73;esuai kebutuhan **→&#x20;**&#x4C;alu klik **Simpan.**
7. Klik opsi **Import Riwayat → Isi Form&#x20;**&#x73;esuai kebutuhan **→&#x20;**&#x4C;alu klik **Simpan.**\
   \
   Vidio Tutorial: [https://drive.google.com/file/d/1k1McFXrfVryisdXUOXGu0anIHpqMtFZX/view?usp=sharing](https://drive.google.com/file/d/1k1McFXrfVryisdXUOXGu0anIHpqMtFZX/view?usp=sharing)
