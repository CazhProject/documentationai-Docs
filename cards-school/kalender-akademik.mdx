Menu Kalender Akademik pada modul Akademik digunakan admin sekolah untuk mengelola event sekolah, seperti hari libur dan kegiatan akademik, per [instansi](/referensi/glosarium#instansi) dan [tahun ajaran](/referensi/glosarium#tahun-ajaran).

## List Event

Link video: 

Fitur ini digunakan untuk melihat list data event kalender akademik.

### Informasi yang ditampilkan

Tabel event memuat kolom: **Instansi**, **Tahun Ajaran**, **Judul**, **Kategori**, **Mulai**, **Selesai**, **Deskripsi**, dan **Status**.

Data dapat disaring dengan filter: **Instansi**, **Tahun Ajaran**, **Status**, **Dari Tanggal**, dan **Sampai Tanggal**.

### Isian formulir Tambah/Edit Event

| Field           | Wajib                   | Keterangan                              |
| --------------- | ----------------------- | --------------------------------------- |
| Instansi        | Ya                      | Instansi tempat event berlaku           |
| Tahun Ajaran    | Ya                      | Pilihan mengikuti instansi yang dipilih |
| Nama Event      | Ya                      | Maksimal 255 karakter                   |
| Tanggal Mulai   | Ya                      | Format tanggal                          |
| Tanggal Selesai | Ya                      | Tidak boleh sebelum tanggal mulai       |
| Deskripsi       | Tidak                   | Teks bebas                              |
| Kategori Event  | Ya                      | Pilih dari kategori event yang tersedia |
| Status          | Tidak (hanya saat edit) | Status aktif/tidak aktif event          |

<Callout kind="info" collapsed="false">
  Saat event dibuat, sistem otomatis mengirim notifikasi "Ada Event Hari Ini" ke anggota instansi terkait pada hari berlangsungnya event. Jika deskripsi kosong, isi notifikasi menggunakan rentang tanggal event.
</Callout>

## Lihat Kalender

Link video:

<Callout kind="info" collapsed="false">

</Callout>
