# Notifikasi

Admin memiliki kemampuan untuk notifikasi,

Langkah untuk notifikasi :

1. Login ke website, kemudian klik submenu **Notifikasi.**
2. System akan menampilkan navbar dari **Notifikasi**.
   <Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1785834622626-83slzb2ads6-pasted-image-1785834621421.png?fm=auto&auto=compress%2Cformat" width="1918" height="968" alt="" />
3. Pada notifikasi terdapat empat notifikasi yaitu :
   1. Tagihan.
   2. SPMB.
   3. Donasi.
   4. Tabungan.
4. Pada halaman Notifikasi, Admin dapat :
   1. Melihat notifikasi.
   2. Menandai notifikasi sudah terbaca.
