---
title: Log Perangkat Presensi
description: >-
  Panduan mengelola Log Perangkat Presensi di CARDS School: melihat daftar log
  peragkat, mencari data dengan filter, dan mengexport data log perangkat
  presensi.
---
Link video:

Fitur ini digunakan untuk pengguna melihat riwayat kehadiran pada absensi wajah dengan cara sebagai berikut:

<Steps>
  <Step title="Login ke website, kemudian klik menu Akademik" title-type="p">
    Pada sidebar, klik menu **AKADEMIK** untuk membuka daftar pilihan menu akademik.

    <Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1785728140381-n3inn9t5q6-kalender-menu.png?fm=auto&auto=compress%2Cformat" width="1917" height="967" alt="" />
  </Step>

  <Step title="Kemudian klik submenu Log Perangkat Presensi" title-type="p">
    Pada menu AKADEMIK, klik submenu **Log Perangkat Presensi&#x20;**&#x75;ntuk menampilkan halaman Log Perangkat Presensi.

    <Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1785816609316-e9ihmjh5qff-submenu-logdevice.png?fm=auto&auto=compress%2Cformat" width="1917" height="967" alt="" />
  </Step>

  <Step title="Sistem menampilkan List Log Perangkat Presensi" title-type="p">
    Tabel daftar Log Perangkat Presensi menampilkan Nama, Jenis Presensi, Instansi, Kelas, Device, Detail Foto, Status, dan Tanggal Absen.

    <Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1785816627443-fk5s6kac5oq-list-logdevice.png?fm=auto&auto=compress%2Cformat" width="1917" height="967" alt="" />
  </Step>

  <Step title="Klik tombol Filter untuk mencari data sesuai kriteria" title-type="p">
    Pada fitur Filter dapat memilih berdasarkan **Instansi**, **Status**, atau **Kelas**.

    <Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1785816646206-mrhw4dpxp4n-filter-logdevice.png?fm=auto&auto=compress%2Cformat" width="1917" height="967" alt="" />
  </Step>

  <Step title="Klik tombol Excel untuk mengexport data" title-type="p">
    Tombol Excel dapat mengexport data Log Perangkat Presensi dengan hasil file berupa .xlsx

    <Image src="https://blob-cdn.documentation.ai/org-9f0069f2-e3f7-48a0-be6a-ee3f46a1d606/doc-0793c7e9-51db-4bf5-85cf-91406e00f125/1785816666131-wcl0drtiv6r-export-logdevice.png?fm=auto&auto=compress%2Cformat" width="1917" height="967" alt="" />
  </Step>
</Steps>
